# Емкость модели, переобучение и регуляризация

Занятие курса «Искусственный интеллект» для 9 класса. Ученики строят с помощью своей кросс-валидации кривые валидации и кривые обучения для метода k ближайших соседей и дерева решений, раскладывают ошибку регрессии методом k ближайших соседей на смещение и разброс, осваивают бутстрэп, добавляют к логистической регрессии штраф L2 и подбирают его силу. В конце ученики останавливают обучение раньше, чем модель начнет заучивать обучающую выборку.

## Теория (презентация)

1. **Емкость и переобучение.** Ошибка обучения и ошибка обобщения, недообучение и переобучение. Емкость модели: сколько разных правил она может выучить. Кривые валидации для числа соседей и для глубины дерева решений, кривая обучения, диагностика модели по кривым.
2. **Смещение и разброс.** Сто прогнозов тормозного пути для скорости 100 км/ч, разложение ошибки на квадрат смещения, разброс и шум, бутстрэп как способ получить новые выборки из одной.
3. **Регуляризация.** Лишняя емкость из-за степеней признаков, L2-регуляризация как штраф за большие веса, подбор силы штрафа кросс-валидацией, влияние штрафа на уверенность модели, ранняя остановка обучения, бэггинг как голосование моделей.
4. **Практика.** План из семи заданий.

## Практическая работа

| Задание | Что пишем | Главный результат |
|---|---|---|
| Р1 | `validation_curve` | кривые валидации для числа соседей и для глубины дерева решений |
| Р2 | `learning_curve` | кривые обучения для деревьев глубины 2 и глубины 12 |
| Р3 | `predictions_at`, `bias_variance` | смещение и разброс регрессии методом k ближайших соседей |
| Р4 | `bootstrap_sample` | разброс прогнозов, полученный по одной выборке |
| Р5 | `gradient_l2`, `fit_l2` | логистическая регрессия со штрафом L2 |
| Р6 | `poly_features`, `cv_logreg` | лишняя емкость и подбор силы штрафа λ |
| Р7 | `fit_early_stopping` | ранняя остановка обучения |

Задания повышенной сложности: бэггинг деревьев решений, оценка качества по объектам, которые дерево не видело при обучении, случайный выбор признаков (устройство случайного леса), штраф L1, кривая обучения для логистической регрессии.

**Правило работы:** внутри своих функций разрешены только списки, словари, циклы, модули `math` и `random`. Библиотека `scikit-learn` нужна только для загрузки набора Wine и для сверки в задании Р6, `matplotlib` используется только в готовых ячейках с графиками.

## Данные

1. Синтетические данные беспилотного автомобиля: объекты на дороге (пешеход, велосипедист, автомобиль).
2. Синтетические данные о тормозном пути автомобиля в зависимости от скорости (задача регрессии).
3. Набор Wine из scikit-learn: 178 вин трех сортов, 13 химических признаков.

## Как работать
